# 单位移动规则

所有常规移动均在该单位的行动机会内进行，每次最多上下左右移动1格。准备阶段不自动走动，移动后可以在同一次行动中执行技能或普攻。

先收集存活、可定位的敌人，按曼哈顿距离排序，同距离按格子索引排序。进入当前射程则停步；否则优先向最近敌人寻找合法路径，只走路径的第一格。寻路绕过占用格、地图边界及本方不能进入的预留边列；最近目标完全不可达时尝试下一个存活目标。没有敌人或被完全围住时停在原地。不会默认向前移动，也不会跨行边界产生错误的相邻格。

停步射程取普攻射程与**本次已预选、当前可释放的攻击技能射程**的较大值。没有预选攻击技能、技能冷却/沉默/点数条件不满足，或选择吸血、连击增益、护盾等自身/友方增益时，用普攻射程；这些增益的全图施法范围不会让近战单位远远停住。月刃横扫、月华倾泻使用其预选技能射程；月影瞬杀的范围描述的是瞬移后攻击范围，瞬移仍由技能本身执行。人机在移动前选择可用技能，移动后尚未预选时可以补选。

刺客不再自动向己方后排退。初始化时固定记录其突入资格：我方初始位于第2列、敌方初始位于第7列的刺客才有资格。第一次行动优先尝试跳入敌方第8列／我方第1列的空格，同一行优先，其余行依次尝试。该开局特例优先于普通射程停步。落点全满时不覆盖其他单位，改走普通追敌逻辑；原本有资格者在后续行动中可重试。成功突入只发生一次。

其他初始列的刺客始终按最近敌人追击，之后走到第2／7列不会补获突入资格。突入后的普通移动也遵守目标距离与射程，不再依靠固定朝向推进。初始资格由 `BattleInitializationSystem` 保存，普通移动或技能瞬移均不会改写它。

实现：`BattleMovementComponentSystem`、`BattleAssassinComponentSystem`、`BattleInitializationSystem`、`BattleRoundComponentSystem`。检查：`MovementChecks.cs`，以及保留的攻击、刺客和回合检查。

运行：`dotnet run --project Tools/BattleChecks/BattleChecks.csproj`。
