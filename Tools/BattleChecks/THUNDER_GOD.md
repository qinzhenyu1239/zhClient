# 雷神配置与战斗规则

人物配置在 `Assets/Game/AssetsPacakge/Datas/character.csv`，ID `1002`，当前基础数值以表内设置为准。三个技能的ID为100201、100202、100203，技能参数、范围与消耗均读取 `skill.csv`。

- 雷霆重击：选最近一名敌人，造成 `max(0, 1.5 × 攻击 - 防御)` 的伤害。命中后沉默目标下一回合，期间不能普攻或选择/释放技能，仍可移动。当回合未到的行动不被限制。
- 连锁闪电：按曼哈顿距离选最近的三个不同敌人，距离相同时按格子索引排序；不足三人时攻击全部存活目标。各造成目标最大生命值8%的伤害，不扣防御。护盾仍会抵挡伤害，只有实际扣除的生命值（不含过量伤害）转化为施法者护盾。
- 闪电雷云：施放1秒后开始，每秒随机选一名存活敌人，共4次；每次伤害为 `max(0, 2 × 攻击 - 防御)`。雷击击杀时获得自身当时攻击力4倍的护盾；不同击杀与二技能护盾可以叠加。已释放雷云不消耗后续行动或技能点，跨准备阶段继续计时；暂停战斗会暂停，施法者死亡、移除回合组件、结束战斗时停止。重复施放同一人的雷云会刷新四次轰击。

所有技能伤害沿用现有速度命中规则。百分比伤害忽略防御但不穿透护盾。护盾先抵挡伤害，溢出部分才扣生命，吸血也仅按实际扣血计算。每份护盾独立过期，先消耗更早过期的护盾；持续2回合计入获得护盾当回合，在第三回合开始时移除。沉默只作用于下一回合，不取消已经释放的持续雷云。

UI阵容在 `UIBattle_UICtrl.StartBattle` 中通过 `CreateRandomBattle` 生成：双方各上阵1名血狼人、1名雷神、1名月光女神，共6名；每种英雄在每方只出现一次。我方随机分布在第2–4列，敌方随机分布在第5–7列，其余格子留空。每次重新开始战斗重新随机位置；人物使用各自对应数值、技能和图片。人物视图按人物ID选择 `Images/ThunderGod.png`，名称旁显示护盾量与“禁攻”状态。运行时检查器显示护盾、沉默回合和雷云剩余次数。Images已加入YooAsset采集；编辑器启动会重建模拟清单，发布包需按原流程重新构建资源。

双方分别拥有独立的技能点池，每回合各重置为30点。敌方由 `BattleEnemyAIComponentSystem` 在准备阶段随机预选可用技能；行动前尚未预选时再按当前范围、沉默、已行动、技能层数和剩余点数补选。持续连击或雷云尚未到期时避免重复购买。每个单位每回合仍只行动一次，技能替换普攻；没有可用技能时执行普攻，沉默时不能攻击。技能扣点、取消、死亡和失败退款都按预选时所属阵营结算；UI分别显示双方剩余点数。

运行检查：`dotnet run --project Tools/BattleChecks/BattleChecks.csproj`。
